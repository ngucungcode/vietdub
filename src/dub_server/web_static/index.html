THUYẾT MINH NGOẠI TUYẾN · CPU / NVIDIA CUDA

Biến một bản phim thành bản thuyết minh Việt.

Tách lời diễn viên, giữ nhạc và hiệu ứng, dịch cục bộ rồi dựng lại một track thuyết minh hoàn chỉnh — không gửi nội dung lên dịch vụ AI.

GPU chưa sẵn sàngAI đám mây tắt theo thiết kế (trừ bước dịch API nếu bạn bật)
01

Chọn video

Chỉ nội dung bạn có quyền sử dụng

Với MP4/MKV, H.264/AVC được giữ nguyên không mã hóa lại; HEVC SDR được tự động chuyển mã sang H.264/AVC. HEVC HDR10, HLG hoặc Dolby Vision chưa được hỗ trợ; AV1, VP9, VP8 và FFV1 bị từ chối. Ảnh bìa nhúng và thumbnail được tự động bỏ qua.

Chưa chọn video

Video giữ nguyên trên máy chủ này. Có SRT thì cần chọn đúng ngôn ngữ nguồn; không có SRT, hệ thống sẽ dùng ASR.

02

Cấu hình bản tiếng Việt

Nhịp lời thuyết minh
Model và giọng nói nâng cao

Preset 6GB: ASR small, TIGER chunk 30s / context 2s / batch 1, VieNeu v2, dịch qua API (0 VRAM). Nhà cung cấp mặc định là DeepSeek — đổi ở ô nhà cung cấp nếu bạn dùng API khác.

Chỉ model đã cài và xác minh mới chọn được. Cài profile bằng CLI: dub models install-profile maximum --yes.

03

Tiến trình

00:00Chưa có job nào

Job mới sẽ xuất hiện tại đây và tự cập nhật mỗi 3 giây.

Cài đặt

Chưa rõ trạng thái key

Key API chỉ lưu phía máy chủ và không bao giờ hiển thị lại trên dashboard. Một key này dùng chung cho OpenAI và mọi API tùy chỉnh; server local trên máy này thì không cần key. Backend dịch và model API dưới đây là mặc định cho job mới tạo sau đó; bạn vẫn đổi được từng job trong form tạo job.

Khi chọn API, lời thoại được gửi lên nhà cung cấp đó để dịch; tiến trình dịch chạy ngoài worker offline và job sẽ hiện trạng thái “Đang dịch” cho tới khi xong.

05

Kho model cục bộ

Dashboard chỉ chọn model đã cài và xác minh. Bấm “Tải model” để tải nền trên server (không xảy ra trong lúc xử lý job); tải xong thì model hiện “SẴN SÀNG”. Nút “Tải model còn thiếu cho preset 6GB” ở form tạo job tải đúng 4 model của preset đó.

Danh mục model chưa sẵn sàng.

06

Phụ đề trực tuyến

Bí mật được kiểm tra và lưu phía máy chủ; dashboard không đọc lại hoặc hiển thị API key, token hay mật khẩu.

Chưa cấu hình

Nhập API key và tài khoản để máy chủ đăng nhập, kiểm tra token rồi ghi các file secret với quyền hạn chế. Mật khẩu không được lưu.

Sau khi đổi cấu hình, chạy dub stack restart nếu API báo cần khởi động lại. Token hết hạn có thể được cấp lại bằng form này.
